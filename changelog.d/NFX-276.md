### Review gate
- `comment_check.py` has a corpus of real comments from the six repos (NFX-276; Animus gave none that the others lacked), so a new language shape fails the suite instead of surfacing in the next project's cleanup review. `claude/skills/review-loop/scripts/comment_corpus/<language>.json` holds 45 excerpts (Python 10, Kotlin 10, Dart 9, TypeScript/TSX 8, JavaScript 5, shell 3), each with its source (`repo@sha:path:line`, or `reduced from <repo>` for Animus and Yuyay, which may give only reduced excerpts) and the full `line form verdict` list it must give. `test_comment_corpus.py` checks each entry's shape (Python parses, shell passes `bash -n`, no sha or path into a private repo), its verdicts, that cutting its flagged comments leaves the code as `verify` sees it, and that no secret is in the corpus (`session_report.py`'s `SECRET_RE`). A wrong verdict with an open ticket is pinned as `known` with today's `got`, and the test fails once the fix gives `expected` and asks for the marker to be removed: the DEM-72 contract (`known: NFX-269`) is the one today, and the PAP-69 banner is a plain entry since NFX-267 landed. The verdicts come from a new `comment_check.verdicts(path, text)`, which `--all` now uses too, with unchanged output on all four public repos. The delete-comments skill adds a corpus entry for each classifier miss a cleanup finds, in the same PR.
