### Review gate
- `review-gate.py` reads a single literal `cat` heredoc PR body written in the same shell call as `gh pr create` and ignores trailing `rm` cleanup of the body file, eliminating the top false-positive `written` block while keeping non-heredoc writes and stale-file bypasses fail-closed (NFX-321).
- `local-assist` (`local_summary.py`) allows `100.64.0.0/10` (Tailscale / RFC 6598) addresses alongside RFC 1918 and loopback ranges (NFX-321).
