### Via assets
- `/via assets` asks whether a batch's images come from local models on Cesar's PC or from Gemini before the first image, and never picks on its own (NFX-172). `design/assets.toml` can suggest a source per image row with `maker = "local"` or `maker = "gemini"`, and an optional `[makers] local` text names the project's own local tool and runbook; Via shows that text and never runs it. A bad `maker`, `maker` on an SVG row, or `maker = "local"` with no `[makers] local` is refused when the spec loads. `plan` reports each row's `maker` and the local text. `generate` refuses a row suggested `local` unless `--gemini` says Cesar chose Gemini for it, and sends nothing; `prompts` (the web route) leaves those rows out the same way. Local pictures come in with `import --origin "local <tool>"`; Gemini rows go through agy, then Gemini on the web in Chrome on agy's quota stop. Unattended runs make only the Gemini and unsuggested rows. Images never use the billed Gemini API.
