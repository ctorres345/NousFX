### Review loop
- `testfail.py run` no longer runs the suite with the change when `run-check --stamp` already passed on the same tree, branch and check (NFX-209). On NousFX that saves one ~190 s suite per test-fail run. The stamp is matched the way `--mark` matches it (the gate's `stamp_fields` and signed `valid_stamp`, same tree hash) and left in place for `--mark`. Only the restored half runs, and a `  with change:` line says whether the stamp or a run in the clone was used. No stamp, a stale or forged one, another branch or another command: both halves run as before. With a reused stamp there is no passing log, so failure names a green run also prints are not filtered out (documented in `docs/review-gate.md`).
