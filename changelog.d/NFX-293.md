### Review gate
- Budget mode's Neon review no longer stops on docs outside the allow-list (NFX-293). Every NousFX PR edits a doc outside `claude/` and `scripts/`, so `review.py --allow-list --agy-model` exited 4 each time and Tier 3 fell back to `reviewer-high` (#191, #192). Now a changed file outside `gemini_code_paths` that review-loop's `tier.py` counts as a doc (`is_doc`) is left out of the diff and named, never sent: a stderr note `not sent (docs outside gemini_code_paths): ...` and a `not_sent` list in the JSON for the PR's Gemini row. Any other file outside still exits 4, risk-path docs included (`requirements*.txt`, `CMakeLists.txt`, anything under `.github/`: tier.py's `risk_path_hit`), since a deep review must see them; docs alone with nothing inside still exit 5; if `tier.py` cannot be loaded, docs stop the run as before. agy only ever sees the sent diff, in an empty folder, so the allow-list stays the privacy boundary. `references/gemini.md` and the budget-mode skill say so.
