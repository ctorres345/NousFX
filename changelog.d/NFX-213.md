### Review gate
- `prove.py run --base <hash>` flags command proofs that pass without the change (NFX-213). After the normal run it runs each command proof in a temporary clone at the base and prints one line per proof: `passes without the change` (a proof that cannot fail), `fails without the change`, or `unknown` when the base run timed out or the proof also fails in a clean clone of the change (gitignored setup such as `local.properties` or `node_modules`). Flags are print-only: the exit code and the stamp do not change, and review-loop's Record step (`references/record.md`) turns each flag into a `med` finding. `Proof: guard: `cmd`` (the marker NFX-299 names) runs like a command proof and is never flagged, for no-regression checks; an empty `guard:` is refused. The trusted `[check]` command gets no base run, and a base that is not a commit exits 2 before any proof runs.
