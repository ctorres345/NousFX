### Review gate
- PreToolUse Bash hook warns on zsh `$VAR args` commands (NFX-247). When `SHELL` is zsh and a Bash command segment starts with an unquoted `$NAME` or `${NAME}` followed by arguments (such as `P="python3 -B s.py decide K"; $P --why x`), `review-gate.py` emits an advisory warning explaining that zsh does not word-split `$NAME` and suggesting a shell function, an array (`${=NAME}`), or writing the command out. It never blocks (exit 0), skips non-zsh shells, quoted variables, `${=NAME}`, `$(cmd)`, and variables assigned a single-word (no spaces) or array value in the same command.
