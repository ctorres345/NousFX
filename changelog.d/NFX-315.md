### Skills
- Shared skills run their sibling scripts through `~/.agents/skills/<name>`, not `~/.claude/skills/<name>`, so they work on a machine with only agy (NFX-315). This covers after-merge (report, retro, watch ledger), delete-comments, gemini-review, jira-sync, ticket-check's proof lint and review-loop's Argon calls. Sync already links every NousFX skill there, and `~/.claude/skills/<name>` links to the same place, so the trust chain does not change. A new test, `scripts/test_skill_paths_neutral.py`, fails on any `~/.claude/skills` in a skill outside a short allow-list.
