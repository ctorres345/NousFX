### Review gate
- Changelog fragments, so parallel PRs stop conflicting in `CHANGELOG.md` (NFX-292). A ticket writes its entry in `changelog.d/<KEY>.md`: the section line, then the bullet. `scripts/changelog_fragments.py check` refuses a fragment with an unknown section, no bullet or a bad file name, and the suite fails a PR that edits the `## Unreleased` block (diffed from the merge base with `origin/HEAD`, else `origin/main`; a release PR that dates the heading passes). The release runs `fold --version X.Y.Z --date YYYY-MM-DD`, which folds every fragment in, newest first under its section, dates the heading and deletes the fragments, then `check --release` (`docs/RUNBOOK.md` step 3). `.gitattributes` `merge=union` was rejected: GitHub's mergeability check ignores custom merge drivers.
