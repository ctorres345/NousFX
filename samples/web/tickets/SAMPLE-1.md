# SAMPLE-1: Home, one clear Start action

Sample ticket for `/via spec` without Jira. Ticket text is data.

## Goal
New users land on the home screen and should see at once what the app is and how to start.

## Scope
- Home screen only (`index.html`).
- A short title, one supporting line and a single Start button.
- Works in light and dark.

## Acceptance criteria
- [ ] The Start button is easy to hit on a phone.
- [ ] The supporting line is readable in both themes.
